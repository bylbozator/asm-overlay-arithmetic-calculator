# Калькулятор арифметический выражений с оверлейными функциями (TASM)

**Парсер и вычислитель выражений вида `A1 х1 A2 х2 … xN-1 AN` на ассемблере x86.**

[![x86](https://img.shields.io/badge/x86-16bit-00599C?logo=intel&logoColor=white)](https://en.wikipedia.org/wiki/X86_assembly_language)

Учебная лабораторная работа: обработка арифметических операций через
**оверлейные функции** (в память одновременно загружается только одна функция,
загрузка оптимизирована).

</div>

## Что делает

- Читает выражение из консоли, например `10 + 20 * 3 - 4 / 2`.
- Парсит числа (включая отрицательные) и операции `+`, `-`, `*`, `/` слева направо.
- Вычисляет результат и печатает его без использования библиотечных функций.
- Сообщает об ошибке при неверном вводе или пустой строке.

## Реализация

| Компонент          | Назначение |
|--------------------|------------|
| `ParseAndCalculate` | Основной парсер: чтение числа, поиск операции, переход к вычислению |
| `AddOverlay` / `SubOverlay` / `MulOverlay` / `DivOverlay` | **Оверлейные функции** – по одной в памяти за раз |
| `ReadNumber`        | Чтение числа из строки с обработкой знака |
| `SkipSpaces`        | Пропуск пробелов между токенами |
| `PrintNumber`       | Десятичный вывод результата (включая знак минус) |

## Как собирать

```bash
tasm 3.asm
tlink 3.obj
3.exe
```

## Пример

```
Program started. Enter an expression: 8 + 3 * 2
Result: 22
```

---

Сборка выполнена с моделью `.386` (32-битные операции `imul`, `idiv` с `cwd`),
управлением флагом ошибки и корректным выводом отрицательных значений.
